# Microsoft Learn Reporter

POC en Streamlit para consultar los Learning Paths públicos asociados a un perfil de Microsoft Learn.

## Uso
1. Pega la URL pública o username del perfil de Microsoft Learn.
2. Pulsa **Consultar Microsoft Learn**.
3. Revisa los Learning Paths detectados.
4. Descarga el resultado en Excel.

## Despliegue en Streamlit Community Cloud
- Main file path: `streamlit_app.py`
- Las dependencias están definidas en `requirements.txt`.

> Esta es una prueba de concepto. Antes de usarla como solución corporativa masiva, valida con Microsoft y con las políticas internas el uso automatizado de los endpoints públicos consultados.
